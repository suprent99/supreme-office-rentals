# Supreme Office Rentals website

A responsive furniture-rental website starter built with plain HTML, CSS and JavaScript.

## Preview

Open `index.html` in a browser, or run a local static web server from this folder.

## Before launch

- WhatsApp enquiries are configured for `601154209676`.
- Update product names, prices and images in `script.js`.
- Confirm delivery areas, rental terms and damage policy.
- Connect the enquiry flow to your preferred CRM or payment system when ready.
